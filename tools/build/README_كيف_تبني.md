# كيف تبني النظام وترسل لي الأخطاء

## المطلوب مرة واحدة: .NET 8 SDK

نزّله من: **https://dotnet.microsoft.com/download/dotnet/8.0**
اختر: **.NET 8.0 SDK** ← **Windows** ← **x64**
(الـ**SDK** لا الـRuntime — الفرق مهم: الـRuntime يشغّل فقط ولا يبني.)

للتأكد، افتح موجه الأوامر واكتب:
```
dotnet --version
```
يجب أن يظهر رقم يبدأ بـ **8.**

---

## الخطوات

### ١) أنزِل الكود الصحيح

⚠️ **مهم:** الإصلاحات على فرع `arena/01a0792e-tasnee1212` وليس على `main`.

**من المتصفح (الأسهل):**
1. افتح: https://github.com/salahaaa/TASNEE1212/tree/arena/01a0792e-tasnee1212
2. زر **Code** الأخضر ← **Download ZIP**
3. فُكّ الضغط في مجلد مثل `D:\DateERP`

**أو من موجه الأوامر:**
```
git clone -b arena/01a0792e-tasnee1212 https://github.com/salahaaa/TASNEE1212.git DateERP
```

### ٢) شغّل السكربت

انقر نقراً مزدوجاً على:
```
tools\build\ابنِ_وأرسل_الأخطاء.bat
```

سيقوم بـ: التحقق من SDK ← استعادة الحزم ← البناء ← الاختبارات ← تجميع الأخطاء.
**أول مرة قد تستغرق 5–10 دقائق** (تنزيل الحزم).

### ٣) أرسل لي الملف

سيفتح تلقائياً ملف اسمه:
```
tools\build\أرسل_هذا_الملف.txt
```
**انسخ محتواه كاملاً وأرسله لي** — أو ارفعه على المستودع.

## ماذا أتوقع؟

**توقّع أن يفشل البناء في أول مرة.** هذا ليس فشلاً — بل هو المكسب.

الكود لم يُترجم منذ B83، فتراكمت أخطاء عبر ~20 حزمة. أول بناء سيكشفها **كلها دفعة واحدة** بنصوص دقيقة (اسم الملف + رقم السطر + سبب الخطأ)، وأعالجها واحداً واحداً.

الطرف الآخر واجه ~12 خطأ ترجمة عند سحبه للكود — فالعدد المتوقع من هذا الحجم.

## إن واجهت مشكلة

| المشكلة | الحل |
|---|---|
| `dotnet` غير معروف | لم يُثبَّت SDK — أعد التثبيت وأعد فتح موجه الأوامر |
| `لم يُعثر على DateERP.sln` | السكربت خارج مجلد المشروع — تأكد أنه في `tools\build\` |
| النافذة تُغلق فوراً | شغّله من موجه الأوامر لترى الرسالة |
| بطء شديد أول مرة | طبيعي — يُنزّل حزم NuGet |

**أرسل لي أي رسالة خطأ كما هي نصاً — لا تصفها بالكلام.**
