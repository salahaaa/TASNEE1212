# DateERP — دليل التنصيب

## التشغيل بضغطة زر — ثلاث خطوات

| الخطوة | الملف | أين يُشغَّل |
|---|---|---|
| **1** | `1-بناء_الحزمة.bat` | مرة واحدة على **جهاز المطوّر** |
| **2** | انسخ مجلد `DateERP_Publish` كاملاً | إلى **كل جهاز** |
| **3** | `2-تنصيب.bat` | نقرة مزدوجة على **كل جهاز** |

**لا يحتاج الجهاز الهدف تثبيت .NET** — الحزمة مكتفية ذاتياً (`--self-contained`).

---

## الملفات

| الملف | الوظيفة |
|---|---|
| `1-بناء_الحزمة.bat` | يبني وينشر وينسخ الأدوات ويحسب البصمة — **يتوقف إن فشلت الاختبارات** |
| `2-تنصيب.bat` | التنصيب: فحص ← تحقق من البصمة ← نسخ احتياطي للبيانات ← نسخ ← اختصارات ← تشغيل |
| `فحص_المتطلبات.bat` | فحص النظام والمعمارية والذاكرة والمساحة والاتصال بالخادم |
| `إلغاء_التنصيب.bat` | إلغاء نظيف — **يسأل قبل حذف البيانات** |
| `إنشاء_اختصار.ps1` | اختصارات سطح المكتب وقائمة ابدأ (يُستدعى تلقائياً) |
| `server/إعداد_قاعدة_البيانات.sql` | إنشاء القاعدة وضبط خياراتها |
| `server/إعداد_جدار_الحماية.ps1` | قواعد المنفذ 1433 و1434 |
| `server/إعداد_النسخ_الاحتياطي.sql` | نسخة يومية 23:00 مع `RESTORE VERIFYONLY` |

---

## التنصيب على الخادم (الوضع الشبكي)

```
1. server\إعداد_قاعدة_البيانات.sql       ← على الخادم
2. server\إعداد_جدار_الحماية.ps1         ← على الخادم (كمسؤول)
3. server\إعداد_النسخ_الاحتياطي.sql      ← على الخادم
4. 2-تنصيب.bat                           ← على الخادم وكل جهاز عميل
5. بعد أول تشغيل: شاشة «معلومات النظام» ← «تعديل الاتصال» ← اسم الخادم
```

اسم الخادم المقبول: `SERVER01` أو `SERVER01\SQLEXPRESS` أو `192.168.1.10`.
**لا تستخدم `localhost` على الأجهزة العميلة** — فقط على الخادم نفسه.

---

## التنصيب على جهاز مفرد (الوضع المحلي)

```
2-تنصيب.bat  ←  انتهى
```
يعمل البرنامج على قاعدة محلية، وتضبط الخادم لاحقاً من شاشة «معلومات النظام».

---

## بعد التنصيب — تحقّق من ثلاثة أشياء

1. **شريط العنوان** يجب أن يعرض ختم الإصدار. إن لم يظهر فأنت تشغّل نسخة قديمة.
2. **شاشة الدخول** تعرض «آخر دخول» — وإن انتهت صلاحية كلمة المرور تُفرض شاشة التغيير.
3. **البيانات** في `%LocalAppData%\DateERP\`:
   - `config.json` — إعداد الاتصال
   - `dateerp_local.db` — القاعدة المحلية (الوضع المحلي فقط)
   - `logs\` — السجلات

## الأمان

| البند | الحالة |
|---|---|
| كلمات المرور | PBKDF2‑SHA256 بـ100,000 دورة، ملح لكل مستخدم |
| انتهاء الصلاحية | 90 يوماً (قابل للضبط: `SystemSettings/PasswordMaxAgeDays`) |
| القفل | بعد 5 محاولات، وفك تلقائي بعد 30 دقيقة (`SessionIdleMinutes`) |
| مهلة الخمول | خروج تلقائي بعد 30 دقيقة مع تحذير قبل دقيقتين |
| كلمة مرور الخادم | DPAPI — لا نص صريح في أي ملف |
| النسخ الاحتياطي | يومي 23:00 مع تحقق من السلامة |

---

## حل المشكلات

| المشكلة | الحل |
|---|---|
| «لم يُعثر على DateERP.exe» | لم تنسخ المجلد كاملاً بعد البناء |
| «البصمة غير مطابقة» | الحزمة تالفة — أعد البناء والنسخ |
| «فشل النسخ» | انقر `2-تنصيب.bat` بزر الفأرة الأيمن ← «تشغيل كمسؤول» |
| «لا استجابة على المنفذ 1433» | شغّل `إعداد_جدار_الحماية.ps1` على الخادم |
| البرنامج يفتح نسخة قديمة | ابحث عن `DateERP.exe` في الجهاز واحذف النسخ الزائدة |
| `SQL Server Express` بلا Agent | استخدم «مجدول مهام ويندوز» (الأمر في أسفل ملف النسخ) |

## ملاحظة مهمة عن حجم الحزمة

الحزمة المكتفية ذاتياً حجمها **150–250 ميجابايت** (تحتوي بيئة .NET كاملة).
لهذا **لا تُحفظ في مستودع الكود** — تُبنى على جهاز المطوّر وتُنسخ.
إن أردت حزمة أصغر (≈70 ميجابايت) فابنِ بـ`--self-contained false`،
لكنها تتطلب تثبيت **.NET Desktop Runtime 8** على كل جهاز.
