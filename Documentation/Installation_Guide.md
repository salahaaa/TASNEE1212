# دليل التثبيت — Date ERP

## نظرة عامة
نظام سطح مكتب (WPF / .NET 8) متعدد المستخدمين يعمل على شبكة الشركة المحلية (LAN)
ويرتبط بقاعدة بيانات SQL Server مركزية واحدة على السيرفر.

```
        SERVER (SQL Server: DateFactory)
                    │
                LAN Network
        ┌───────────┼───────────┐
      PC-01       PC-02       PC-03
     Date ERP    Date ERP    Date ERP
```

## 1) متطلبات السيرفر
- نظام Windows مع **Microsoft SQL Server** (2016 أو أحدث — بما فيها Express).
- **أدوات سطر الأوامر** `sqlcmd` (تأتي مع SQL Server أو عبر Microsoft ODBC Tools).
- منفذ الجدار الناري **TCP 1433** مفتوح (للـ Default Instance)، أو منفذ ثابت للـ Named Instance (§15).
- خدمة **SQL Server Browser** تعمل عند استخدام Named Instance مثل `SERVER01\SQLEXPRESS`.

## 2) تثبيت بيئة السيرفر
1. شغّل **`DateERP_Server_Setup.exe`**.
2. عند انتهاء التثبيت اختر "إنشاء قاعدة البيانات الآن" وأدخل اسم الخادم.
   - السكربت ينشئ `DateFactory` إن لم تكن موجودة، ثم المخطط، ثم البيانات الأساسية.
   - **لا يحذف أي قاعدة بيانات موجودة أبداً.**
3. كلمة المرور الأولية لجميع المستخدمين: **`Admin@123`** — النظام يجبر كل مستخدم على تغييرها عند أول دخول.

### إعداد الجدار الناري (مثال)
```powershell
New-NetFirewallRule -DisplayName "SQL Server" -Direction Inbound -Protocol TCP -LocalPort 1433 -Action Allow
New-NetFirewallRule -DisplayName "SQL Browser" -Direction Inbound -Protocol UDP -LocalPort 1444 -Action Allow
```

## 3) تثبيت الأجهزة (كل جهاز مستخدم)
1. انسخ **`DateERP_Client_Setup.exe`** إلى الجهاز (عبر الشبكة أو فلاش).
2. شغّله — يُنشئ: مجلد التطبيق، اختصار سطح المكتب، اختصار قائمة ابدأ، وبرنامج الإزالة.
3. لا يحتاج الجهاز أي شيء آخر: التطبيق **Self-contained** (لا يتطلب تثبيت .NET يدوياً).

## 4) أول تشغيل على أي جهاز (§12)
1. نقرة مزدوجة على **Date ERP** في سطح المكتب.
2. تظهر شاشة "إعداد اتصال النظام" مرة واحدة فقط:
   - اسم الخادم: `SERVER01` أو `SERVER01\SQLEXPRESS` أو `192.168.1.10`
   - قاعدة البيانات: `DateFactory`
   - المصادقة: **Windows Authentication** (موصى به)
3. اضغط **اختبار الاتصال** — تظهر النتائج التفصيلية:
   `الخادم ✓ | خدمة SQL Server ✓ | قاعدة البيانات ✓ | بيانات الدخول ✓ | الاتصال الكامل ✓`
4. اضغط **حفظ الإعداد** ثم سجّل الدخول.

## 5) المصادقة (§13)
- **الموصى به:** Windows Authentication — لا توجد كلمات مرور قواعد بيانات في الملفات.
- خيار SQL Authentication متاح إدارياً وتُشفَّر كلمة مروره محلياً بـ DPAPI ولا تُخزن نصاً صريحاً.
- لا يوجد أي سر في: الكود المصدري، ملفات الإعداد، المثبّط، أو السجلات.

## 6) النسخ الاحتياطي (§29/§30)
- خطة يومية كاملة تُثبَّت تلقائياً على SQL Server Agent مع **تحقق الاستعادة (RESTORE VERIFYONLY)**.
- من داخل النظام: شاشة **النسخ الاحتياطي** (نسخة كاملة + تحقق + استعادة بصلاحية إدارية).
- احفظ النسخ على قرص/موقع منفصل عن قرص قاعدة البيانات.

## 7) التحديث (§33)
- لكل إصدار جديد: `DateERP_Client_Setup.exe` جديد — ثبّته فوق القديم على كل جهاز.
- يمكن مستقبلاً التوزيع التلقائي من مجلد شبكة داخلي مثل `\\SERVER01\DateERP\Releases\`.
- ترحيل قاعدة البيانات عبر `Upgrade.sql` بعد نسخة احتياطية مُتحقق منها (§32).
