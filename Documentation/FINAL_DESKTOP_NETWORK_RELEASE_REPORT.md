## قائمة التحقق النهائية على أجهزة الشركة (§45)
هذه البنود لا يمكن تنفيذها إلا على شبكة الشركة الفعلية، وهي خطوات محددة بوضوح:

```
□ تشغيل Build-Release.ps1 على جهاز ويندوز فيه .NET 8 SDK + Inno Setup
  → ينتج DateERP_Server_Setup.exe و DateERP_Client_Setup.exe
□ تثبيت السيرفر وإنشاء القاعدة عبر المثبّط (اختبار الاتصال ✓ خماسي)
□ تثبيت العميل على جهاز نظيف (بلا .NET/تطوير) → تشغيل → إعداد اتصال → دخول
□ اختبار إعادة تشغيل ويندوز ثم نقرة مزدوجة على الاختصار
□ اختبار 3 أجهزة متزامنة (استلام/مشاهدة/تخطيط ثم صرف/تنفيذ/متابعة)
□ اختبار تعارض: مستخدمان يعدلان نفس السجل → الثاني يُرفض برسالة واضحة
□ اختبار انقطاع الشبكة أثناء الحفظ → لا حفظ جزئي ثم استئناف طبيعي
□ التحقق من الطباعة ومعاينتها وتصدير PDF/Excel على طابعة فعلية
□ نسخة احتياطية + استعادة اختبارية ناجحة
```
