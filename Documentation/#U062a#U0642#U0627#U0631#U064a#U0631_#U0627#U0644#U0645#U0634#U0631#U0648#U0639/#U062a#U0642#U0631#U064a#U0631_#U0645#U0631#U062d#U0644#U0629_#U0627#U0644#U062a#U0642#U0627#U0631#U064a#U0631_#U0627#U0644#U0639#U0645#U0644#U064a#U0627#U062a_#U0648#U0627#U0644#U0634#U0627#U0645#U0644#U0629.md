## 1) مركز التقارير الجديد (الشاشة)
- قائمة تقارير **مصنفة**: «تقارير العمليات» و«التقارير الشاملة» + التقارير السابقة كلها.
- **فلاتر ديناميكية** تظهر حسب التقرير: من/إلى تاريخ، العميل، الصنف، نوع العملية، قرار الجودة.
- المعاينة **داخل نفس الشاشة**: بطاقات مؤشرات (الإجماليات) أعلى الجدول + الجدول + عدد الصفوف — بلا نوافذ ثانية.
- طباعة / تصدير PDF / تصدير Excel بهوية المصنع (الشعار واسم الشركة في الترويسة).

| **سجل العمليات الموحد** | دورة العمل كاملة في دفتر واحد: 📥 استلام / 📋 خطة / 📝 أمر / 🏭 إنتاج فعلي (مع حشف/نوى/هالك) / 🔬 فحص / 📦 استلام تام / 🚛 تسليم | نوع العملية، عميل، من/إلى |

## 3) التقارير الشاملة

| التقرير | المحتوى |
|---|---|
| **كشف الصنف الشامل** | الرحلة الكاملة لكل صنف: المستلم/المخطط/المنتَج/المقبول/مخزون التام/المسلَّم/المفوتر/المتبقي — يجيب مباشرة: «كم استُلم من السكري وكم أُنتج وفُحص وسُلّم وما المتبقي؟» |
| **كشف العميل الشامل** | لكل عميل: الاستلام/التخطيط/الإنتاج/القبول/مخزون التام/التسليم/الفوترة/غير المفوتر |
| **تقرير الإنتاج اليومي** | لكل جلسة: الأمر/العميل/الأصناف/المنتَج كجم+كراتين/حشف/نوى/هالك/التوقفات (ساعات) + إجماليات |
| **تقرير الفحص التفصيلي** | لكل فحص: القرار (إفراج/حجز/رفض) + المعايير المخبرية (رطوبة/سكريات/قشرة/شوائب) + المقبول/المرفوض + نسبة القبول |

## 4) الاختبارات (105/105 — منها 7 للتقارير الجديدة)
دورة كاملة مُختبَرة آلياً (استلام سكري 10,000 + خلاص 8,000 ← خطة ← أمر ← إقفال بتوقفات ومخرجات ثانوية ← فحص بمعايير وقرار ← تام ← تسليم ← فاتورة) ثم التحقق من:
- حركات التوريد: وحدة «سلة» الأصلية محفوظة + الكمية كجم + فلتر الصنف.
- حركات الخطط: الإجماليات (مخطط 13,500 / منتَج 13,100 / مسلَّم 1,500) وكل سطر بمرجعه (دفعة وشحنة).
- سجل العمليات: الأنواع السبعة حاضرة + فلتر النوع يعمل.
- كشف الصنف: سكري — مستلم 10,000 / مخطط 7,500 / منتَج 7,500 / مقبول 7,300 / مخزون 6,300 / مسلَّم 1,000 ✓.
- كشف العميل: المراحل الثماني بأرقامها ✓.
- الإنتاج اليومي: المنتَج 13,100 + حشف 200 + نوى 150 + هالك 50 + توقفات 1.5 س ✓.
- الفحص التفصيلي: رطوبة 15.8 / سكريات 69.2 + قرار مطابق + فلتر «مرفوض» بلا نتائج ✓.

## 5) ما التالي في مرحلة التقارير (الحزم القادمة عند الطلب)
1. **تقارير الفقد والطاقة**: طاقة الوردية − المنفذ = الفقد، تحليل التوقفات بأسبابها (بيانات التوقفات موجودة في الإقفالات).
2. **تقارير المواد**: استهلاك المواد المساعدة (المعادل مقابل الفعلي) ومطابقة الأرصدة.
3. **مصفوفة العملاء × الأيام** (الأسبوعين) وتقرير الجاهزية والتأخير.
4. **الملخص التنفيذي** (لوحة مؤشرات يومية: استلام/إنتاج/تسليم اليوم + تنبيهات).

## 6) على جهازك بعد التحديث
افتح شاشة التقارير ← اختر «سجل العمليات الموحد» وشغّله بلا فلاتر (سترون الدورة كلها) ← ثم جرّبوا الفلاتر: نوع العملية «تسليم»، عميل معين ← ثم «كشف الصنف الشامل» واختر صنفاً ← ثم اطبع أو صدّر أي تقرير. إن أردتم أرقاماً أو أعمدة إضافية في أي تقرير أرسلوها وتُضاف في الحزمة التالية.
