## 🔴 Q1 — قرار الجودة **لا يُنفَّذ إطلاقاً**: فحص مرفوض 100% يفتح بوابة التسليم — مُثبت بالتشغيل

**الدليل الأول — `ApproveCheck` (`ExecutionService.cs:600‑620`) لا يحتوي أي تفرّع على القرار:**
```csharp
return RunOp(() =>
{
    check.IsApproved = true;
    check.Status = DocStatuses.Approved;
    …
    if (check.OrderId != null) PlanSync.SyncAccepted(Db, check.OrderId.Value);
    string decAr = check.Decision switch { "Quarantine" => " (قرار: حجز وتحريز مؤقت)", "Rejected" => " (قرار: مرفوض/عوادم)", _ => "" };
    return OpResult.Success($"تم اعتماد فحص الجودة{decAr}.", …);   // ← القرار يظهر في نص الرسالة فقط
});
```

**الدليل الثاني — بوابة التسليم تفحص `IsApproved` فقط لا `Decision`:**
```csharp
// CustomerDeliveryService.cs:82
var qualityApproved = Db.QualityChecks.Any(c => c.OrderId == gateOrderId && c.IsApproved);
```

**الاختبار (شغّلتُه على الكود الحقيقي)** — فحص بكل كمياته مرفوضة، ومعاييره خارج الحدود كلها (رطوبة 30% مقابل 14‑18، Brix 20 مقابل ≥65، انفصال قشرة 40% مقابل ≤5، شوائب 15% مقابل ≤1):
```
SaveCheck  Ok = True   تم حفظ فحص الجودة QC-2026-0001 — مقبول 0.0 كجم.
ApproveCheck on a REJECTED check -> Ok = True
   message = تم اعتماد فحص الجودة (قرار: مرفوض/عوادم).

   Decision   = Rejected
   IsApproved = True
   AcceptedKg = 0     RejectedKg = 1000

   delivery gate  Any(OrderId==order && IsApproved)  =  True
   => delivery to the customer is UNLOCKED even though the batch was fully rejected
```

> **النتيجة:** دفعة **تالفة بالكامل** تُعتمد وتُفتح للتسليم للعميل. ورسالة الواجهة بعد الاعتماد تقول *«أصبح بالإمكان تسليم إنتاج هذا الأمر للعميل»* — **وتظهر حتى للمرفوض**.

**السياق:** تقرير المطوّر نفسه يذكر أن القرار «يُحفظ في القاعدة ويظهر في رسالة الاعتماد والطباعة والسجل» — أي أنه **معروض** فعلاً. لكنه **غير مُنفَّذ**. والفرق بين العرض والإنفاذ هو الفرق بين تقرير ورقى وضابط فعلي.

## 🔴 Q2 — لا سقف على «المقبول» مقابل ما أُنتج فعلياً

```csharp
// SaveCheck — الفحص الوحيد هو السالب
if (it.AcceptedQtyKg < 0 || it.RejectedQtyKg < 0) throw new DomainException("الكميات لا يمكن أن تكون سالبة.");
…
CheckedQtyKg = it.CheckedQtyKg > 0 ? it.CheckedQtyKg : it.AcceptedQtyKg + it.RejectedQtyKg,
```
**«المفحوص» مُشتق من «المقبول + المرفوض»** — لا مُتحقَّق منه مقابل المنتَج في الأمر أو في بند الخطة.
> يمكن تسجيل قبول 10,000 كجم من أمر أنتج 100 كجم، ويُعتمد.

## 🔴 Q3 — `SyncAccepted` يقتطع المقبول **بصمت** عند سقف المخطط

```csharp
// PlanSync.SyncAccepted
pi.AcceptedQtyKg = Math.Min(pi.PlannedQtyKg, accepted);
```
وبما أن الإقفال سبق فكتب `pi.PlannedQtyKg = pi.ProducedQtyKg` (علّة §مرحلة الإقفال)، يصبح السقف هو **المنتَج** — فالقبول الزائد **يُقتطع بصمت بدل أن يُرفض برسالة**. الرقم يُصحَّح في القاعدة ويضيع الدليل على الإدخال الخاطئ.

|---|---|
